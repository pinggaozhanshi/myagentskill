# Agent entrypoint

当任务是在 ACE Studio 里调教合成人声（默认洛天依 V1）——尤其是以原唱为参考的翻唱：建工程、核对谱面与读音、调时值、写音高曲线、
修音节结尾、表情参数、音量对齐盲听、混音交付或交付后修改——先读同目录的 SKILL.md，再按其中的表格读相关参考。

本包适用于任何能读 UTF-8 文件、能运行 Python 的 Agent。脚本要复制进具体项目的 `scripts/` 并配 `project.json` 才能运行（见 references/setup.md）；
ACE 必须由用户或经用户同意打开。用户授权和宿主权限优先：下载、上传到 ACE 云端、发布都要先问。
不要把案例里的歌名、音符序号、BPM、路径或电平差当作新任务的默认值；照用的是规则和阈值。
