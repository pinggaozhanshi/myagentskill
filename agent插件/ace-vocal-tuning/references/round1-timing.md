# 第 1 轮：时值（只改清辅音长度与句尾释放）

目标：让每个字的“前一元音结束 → 本字元音到达”与原唱一致。症状是“字被唱短 / 被拖长”：
合成的清辅音太长，会提前切断前一个元音；太短，前一个字就被拖长。音符、歌词、音高、参数都不动。

## 怎么量（`timing_voicing.py`）

强制对齐（SOFA 等）在合成声和分离出来的人声上都不稳，所以用**有声 / 无声边界**来量：

- **测哪些音**：首辅音是清辅音的音，以及休止后的音（清辅音表在 `common.VOICELESS_INIT`，按语言选）。
- **元音到达**：音符起点附近 [−70, +90] ms 内，一段连续无声之后的第一个有声帧（Praat，5 ms）。
- **前一元音结束**：这段无声开始的地方。
- **间隙** = 到达 − 结束（含闭塞、爆破、擦音或休止）。
- **测不了的**：浊辅音、纯元音开头的音这样量不出来，记为不可测；`target=False`、`timing=False` 的音也不测。

| 曲目 | 可测音 |
|---|---|
| 《超级超级超级讨厌》 | 106 / 112 个（加了 SOFA 的元音起点） |
| 《反乌托邦》 | 83 个里 32 个清声母 |
| 《妄想感傷代償連盟》 | 37 个候选里 36 个 |
| 《绯红》 | 91 个候选里 69 个 |

**测不到的一类问题**：前一个音的元音被下一个辅音整个吃掉时，没有“前一元音结束”可测，这一轮不会改它。
快歌（十六分音符 ≤ 150 ms）尤其常见，第 2 轮之后用结尾检查找（`round-endings.md`）。

参考和合成的 wav 都从片段起点开始（`make_reference.py` 截参考，与 ACE 导出同起点、同长度）。

## 规则：运行前定死，写进 `round1_timing.py`，不看结果改规则

先跑不带 `--apply` 的计划，核对后再 `--apply`。

| 规则 | 内容 |
|---|---|
| A 辅音长度 | `diff` = 合成间隙 − 参考间隙；`|diff| < 15 ms` 不改 |
| A1 偏长（diff > 0） | 新长度 = max(20 ms, 当前 − diff)；diff 超过“当前辅音长 − 15 ms”记为非时值原因、不改 |
| A2 偏短（diff < 0） | 新长度 = 当前 + |diff|，不超过 200 ms；超过记为非时值原因 |
| B 句尾释放 | 休止后的音：前一元音结束差 ≥ 30 ms 时调前一个音的终点；不与后一个音重叠，至少留 60 tick |
| B 上限 | 释放差 > 300 ms 不改。参考的长休止里常有零星的分离残留帧，会被当成“前一元音结束”：《反乌托邦》差点把两个 0.25 s 的字拉成 1.6 s |
| C 共用间隙 | 相邻两个清辅音量到同一段无声时，只改后一个 |
| D 快歌保护 | 拉长辅音不超过前一个音时长的 70%（220 BPM 的十六分音符只有 68 ms） |

`--apply` 之前人工看一遍计划里的句尾释放：**促音、短休止前的音不要延长**。《绯红》#179 后面是 147 ms 的促音休止，
规则 B 把它延长 24 tick 后只剩 118 ms，ACE 就把元音一直唱到下一个辅音（停顿 原唱 90 / r0 135 / r1 10 ms）。
规则本身不拦这种情况：看到了就加 `--skip <序号,...>` 重跑计划（被排除的音辅音和时值都不改，计划里记“人工排除”），再 `--apply`；
漏了的话，第 2 轮开头用 `round2_pitch_online.py --revert` 改回。
不设“剩下的休止少于多少毫秒就不延长”的自动阈值：《妄想感傷代償連盟》#12 延长后休止只剩 106 ms（220 BPM），实测变得更接近原唱、没有被唱过去；
《绯红》#179 剩 118 ms 却被唱过去了。会不会被唱过去和速度、前后的音素有关，一个数说不清，所以靠 `--apply` 前人工看、第 1 轮之后查每个休止还在不在。

`--apply` 前脚本会确认 ACE 里开着的就是 state 里那个已保存的工程（不是就停）。它另存出 r1、改完、保存，但不写新的 state：
用它打印的 savedPath 跑 `python -I scripts/state_with_project.py work/ace_state_r0.json <savedPath> work/ace_state_r1.json`。

## 验收（`compare_timing.py`）

- **被改的音**：离参考更近还是更远（差 ≥ 5 ms 才算）。四次试验：
  - 18 个里 16 个更近、0 个更远；
  - 31 个里 28 个更近、0 个更远（中位 30 → 5 ms）；
  - 19 个里 18 个更近、1 个更远（中位 40 → 5 ms）；
  - 《绯红》34 个里 30 个更近、0 个更远（中位 50 → 5 ms），句尾释放 3 处里 2 个更近、#179 变远（就是上面那个被唱过去的休止）。
- **没改的音**：有没有被连带改变（ACE 会重算整个片段）。三次的中位数都没变，个别音变动超过 10 ms，要列出来。
- **更远的音按规则不回改**：记作退步，在第 2 轮之后再看一次。例外是停顿消失（休止被唱过去）：那是错误，下一轮开头改回原时值。
  - 例：《妄想感傷代償連盟》#14 拉长 k 后，闭塞里出现一小段被 Praat 判成有声的声音，间隙被量成 10 ms；
  - 到 r2 时这一处已不再变差。
- **附带改善也记下来**：《超级超级超级讨厌》#50「あ」被下一个字 81 ms 的 t 吃掉大半，第 1 轮把 t 缩到 26 ms 后恢复（有声比例 22% → 91%）。
  - 这类问题第一次被误判成起音 / 表情问题，后来撤回。
