# 第 2 轮：音高曲线（写入原唱的音高）

四次试验里收益最大的一轮：音高误差中位 63 → 5、33 → 3.3、18–20 → 2.7–3.2、25 → 2.9 音分；前三次盲听调教版都胜（《绯红》没做盲听）。
音符、歌词、辅音长度与第 1 轮完全相同（`--revert` 改回的个别音除外），只多一条用户音高曲线。

## 目标曲线（`build_target_f0.py`）

输入：整首参考人声的两条 F0（Praat、RMVPE，5 ms，t=0 = 音轨 0 s），按片段起点截取。规则（四次试验相同，第三次起加了折回八度）：

1. **只在音符时间内取值**：前后各放宽 30 ms；休止中不给值，交回 AI 音高，不跨休止连线。`target=False` 的音不给值。
2. **逐帧二选一**：Praat 与 RMVPE 中取离当前音符音高更近的；两个都偏离 > 9 半音就留空。
3. **折回八度**：某个提取值离音符 > 9 半音、平移整八度后 ≤ 2 半音时，把平移值也当候选；距离相同时优先不平移的。用在原曲叠了低八度人声的长音上。
4. **补洞**：有声段内 ≤ 40 ms 的空洞线性插值。
5. **去尖刺**：与前后 35 ms 中位数差 > 2.5 半音的帧，换成中位数。
6. **平滑**：3 帧中值滤波。
7. **不额外加颤音**。

输出 `target_f0.json`：每 5 ms 一个 MIDI 值（片段起点为 t=0）和连续段列表；同时出 Hz 版的 npy，供评估用。

## 重复句：先找模板，一句一条曲线

原唱是 VOCALOID 时，同谱面的句子常常是同一条曲线复制的。《呐呐呐》7 处同谱面的句子，官方和声 6 处里，其余 5 处和第一处只差 1.9–3.8 音分（中位）。
这时不要每次重复都各自从参考取值：参考干净的那次才是真的，其他几次被和声盖着，取出来的是和声、噪声或被规则切过的残缺版本。

**写目标之前先跑 `repeat_phrases.py`**，每组重复句：

1. 挑没有别的声部盖着的一次当模板（`--others` 给和声轨，“被盖 0%”的那次）。
2. 其他几次抄模板的曲线，不再各自取值：
   - 同调照抄，移调加半音数。
   - 和声按“主唱音 → 和声音”的折线映射，不要加固定音程（音程逐音不同，如 64→60、67→64、69→66）。
   - 模板结束后 60 tick 内淡回这一句原来的曲线。
3. 读出整段片段的曲线，改完**整段写回**：局部写入时 ACE 会在范围末尾留一个断开标记（约 4 ms 缺口）。
4. 量每一次和模板的距离（`examples/ust_呐呐呐/final_phrase_match.py`）：音高 p90 应降到几十音分以内。

旋律不同的句子不能硬抄（《呐呐呐》10 处里 3 处旋律不同），按模板的做法处理：保留滑音、去掉折返，和声用官方和声参考。

**案例**：用户听 v2 后说“所有呐呐呐里只有全曲开头那一句最符合原唱”。开头是独唱，其他 6 处有和声，
目标规则“有和声的帧，离谱面 > 1.25 半音的参考不用”把 3 半音的起音上滑、提前下滑全切了，第三个音的上滑还变成 67 → 69 → 67.9 → 69 的台阶。
抄模板后和开头的音高差 p90 从约 200 音分降到 3–24 音分，和声从约 250 降到 8–12。音量走向没有对齐：原唱这几处都很平，开头的音量起伏不是原唱的特点。

### 不要按“离谱面多远”筛参考

大滑音不是噪声，是这句最有辨识度的动作。“离谱面 ±N 半音以内才用”这类保护带，切掉的正是它们。

- 有和声时，用已知的和声曲线排除和声本身（离和声及其八度 < 0.5 半音的值不用），不要用离谱面的距离。这一条只估算过（《呐呐呐》312 个有和声的主唱音约 83 个会变），还没在 ACE 上验证。
- 切完留下的洞别退回谱面基线：滑音中间退回基线就是“台阶”。宁可整段滑音都用模板。
- **“离目标几音分”查不出这种错**：目标本身错了，指标照样好看（v2 是 3 音分）。目标曲线写完要抽查：同谱面的几句放在一起比，差超过 1 个半音、持续 100 ms 以上的要解释。

## 写入：两种方法

| | 离线（前三次） | 在线（《绯红》） |
|---|---|---|
| 脚本 | `round2_pitch.py` → `patch_pitch.py`（LibreSVIP 改 `.acep`） | `round2_pitch_online.py`（`vocalpitch write`） |
| CLI 版本 | 0.17 起都行 | 0.18 起 |
| 写什么 | `pitchDelta` = 目标 − `BasePitchCurve`，每 tick 一个值 | 每 5 ms 一个锚点：`[片段内 tick, 绝对半音]`，连续段之间放 `[tick, null]` |
| 工程 | 写时不能在 ACE 里开着（脚本自动切换） | 直接改开着的工程（r1 另存为 r2 之后） |
| 读回 | 解包逐值比，其余字段与 r1 逐字段相同 | `vocalpitch read --level user` 逐点相同（断开标记存在两段中点） |
| 副作用 | 无 | **把写入当时 ACE 的有声 / 无声判断固定在曲线下**，之后必须清成 auto（下面“写完以后”） |

两种都只写原唱有声处（目标为空的地方不写）。

### 离线写（`round2_pitch.py` → `patch_pitch.py`，LibreSVIP）

- `pitchDelta` = 目标 MIDI − `BasePitchCurve`（由音符重建的 ACE 基础音高），每 tick 一个值；目标为空的地方不写。
- **写入前的八度 / 错音检查**（任一条命中就中止）：
  - 任一音符中段 60% 的 delta 中位数 > 6 半音；
  - |delta| > 9.5 半音持续超过 50 ms。
- 第一次用“|delta| > 7 的占比”做粗检查，结果把大音程过渡、辅音闭塞处的短促下沉、句尾回落都误伤了，后来改成上面两条。
  - 实测：参考滑音造成的“整段偏离”最多 4.4 半音，不是错音。
- 回读：曲线值一致，`pitchDelta` 以外所有字段与 r1 逐字段相同；ACE 打开 r2 后音符与 r1 完全一致。
- 写的时候 r2 不能在 ACE 里开着（`round2_pitch.py` 自动做“另存 r2 → 切回 r1 → 写 → 打开 r2”）。

### 在线写（`round2_pitch_online.py`，0.18 起）

- 当前工程必须是已保存的 r1；脚本另存为 r2，按 `--revert` 改回个别音的时值（例如被唱过去的促音休止），再一次写入全部锚点。
- 《绯红》：31 段、8904 个点（含 30 个断开标记），读回逐点相同；音符除 #179 外与 r1 相同。
- 写入前自动过八度 / 错音检查（`target_check.py`，两条规则同上，基准换成音符音高）；不过就不动工程。
  四条真写过的目标曲线（《绯红》、《妄想感傷代償連盟》试验段 / 完整副歌主唱 / 和声）都通过，把一个长音整体抬高 12 半音会被拦下（回归验证里测过）。

### 写完以后（在线写必须做，离线写建议做）

1. 照常渲染导出（导出前重开工程，见 `revisions.md`），跑下面的评估。
2. **结尾检查**：`vowel_coverage.py`（原唱在唱、合成没声音的帧）、`ace_dump.py voicing` + `voicing_check.py`（被固定成无声的元音）、
   `ending_check.py`（结尾交给 ACE 自己音高的尾巴、结尾时间）。
3. 有问题就做音节结尾轮（`round-endings.md`），它最后一步把固定清成 auto；没问题也要用 `voicing_clear.py` 把固定清掉（在线写的工程）。
   《绯红》r2 直接交付成 v1，用户听出“有些音节的结尾没处理好”，就是这三类问题。

## 评估（`pitch_eval.py`、`glitch_check.py`）

- **只在“参考有值、合成有声”的帧上比较**：|差| > 600 音分算八度 / 错音帧，单独计数，不进中位数。
- **报告这几项**：中位、p90、±50 音分内的比例，以及逐音符“比基线好 / 差 > 30 音分”的个数。两个提取器各报一份。
- **颤音叠加检查**：目标连续段 ≥ 250 ms，F0 去趋势后 4–9 Hz 带通的均方根（音分）。合成明显大于目标，就是叠了颤音。三次都是调教版略平于原唱，没有叠加：

  | 曲目 | 原唱 | 基线 | 调教版 |
  |---|---|---|---|
  | 《超级超级超级讨厌》 | 57 | 52 | 40 |
  | 《反乌托邦》 | 47 | 47.5 | 37 |
  | 《妄想感傷代償連盟》 | 24 | 32 | 25–31 |
  | 《绯红》 | 25.1 | 40.5 | 17.2–18.2（r2）；音节结尾轮后 24.8–29.7 |

- **断声审计**（`glitch_check.py`）：
  - 音符中间 60% 里，参考有声而合成连续无声 ≥ 20 ms 的地方；
  - 断声之后到音符结束都无声的，是下一字的清辅音提前开始（“间隙边缘”），不算；
  - 两侧都有声的才是真断声，要列出秒数请用户听。Praat 单独看到、RMVPE 正常的，多半是 Praat 误判。
- **音高曲线断点**（人工检查，没有脚本）：看合成 F0 在哪里断开，逐个对到真实休止、清辅音、っ。《超级超级超级讨厌》21 个断点：9 个在休止，12 个在清辅音或っ，0 个解释不了。

## 结果（四次试验）

| | 基线 | 调教版 | ±50 音分内 | 变差的音 |
|---|---|---|---|---|
| 《超级超级超级讨厌》（日语，官方清唱） | 63 音分 | 5 | 45% → 92% | 0 |
| 《反乌托邦》（中文，音轨 − 伴奏） | 33 | 3.3 | 64% → 96% | 0 |
| 《反乌托邦》一分钟版 | 31 | 3.5 | 64% → 96% | 0 |
| 《妄想感傷代償連盟》（日语，去混响分离） | 18–20 | 2.7–3.2 | 65–67% → 97% | 0 |
| 《妄想感傷代償連盟》完整副歌主唱 / 和声 | 21 / 20 | 3.2 / 3.1 | 66% → 98% / 65% → 96% | 0 |
| 《绯红》一分钟版（日语，去混响分离，在线写） | 24.7 / 25.9 | 2.9 / 2.8 | 65% → 97% / 64% → 98% | 0 |

（《绯红》两个数分别是 Praat / RMVPE；RMVPE 对 ACE 输出常报 20–60 ms 的“元音中间断声”，Praat 判 r2 为 0 处，以 Praat 为准。）

## 要知道的限度

- **“更接近原唱”≠“更好听”**：调教版照搬了原唱（初音、星尘 / 诗岸）的滑音习惯，换到洛天依身上是否自然，只能靠盲听判断。
- **基线本来就贴着音符的歌，提升空间小**：《妄想感傷代償連盟》的原唱 Miku 贴着音符唱，基线只有 18–20 音分，差距主要在快速连音的过渡。
- **副歌太高的歌**：例如主旋律在 F5、句尾滑到 C6，对洛天依偏高。要不要变调由用户决定（看官方规约是否允许）。
- **曲线只写在原唱有声处**：合成的元音比原唱长的地方（多在结尾），由 ACE 自己的音高接管，会下滑、乱飘。
  《绯红》r2 有 8 处结尾尾巴偏 0.5–3.7 个半音（如一处乐句结尾最后 30 ms 掉了约 1 个半音，原唱只掉 0.2）。音节结尾轮的规则 F 补全曲线。
