# 第 3 轮：表情参数（可选，用户要求时才做）

做过两次，**两次盲听都没有胜过第 2 轮**：

- 《反乌托邦》：四个参数一起改，用户听出来了，觉得“沙哑”；
- 《妄想感傷代償連盟》：只用力度追“干脆”，用户“差别很小，我感觉是甲（r2）”。

成品都留在 r2。所以这一轮默认不做；用户提出某种具体听感（如“原唱更干脆”）时再做，并单独盲听。

## 洛天依 V1 的参数（官方文档《V1 模型的人声参数》已核对）

- V1 = Verse24 及更早；Verse23 是 V1。
  - 表情参数：气声（air）、假声（falsetto）、张力（tension）、力度（energy），另有共振峰；
  - 没有 V2 的“动态”，也没有音素时长编辑。
- 官方建议：小幅调整、多数情况只改包络（倍率）。
  - 要更多假声就同时降张力（低音区提假声可能无效）；
  - 要更柔和就力度、张力一起降。
- 两种编辑：包络（相对值，橡皮擦回 1×）和 “Par.” 真实参数（绝对值，画过即成用户参数，不再重生成）。
- 共振峰：调高更像女声 / 童声，调低更厚重（四次试验都没动）。
- 颤音不要叠：长音上 AI 音高往往已带颤音；要换颤音，先画平直的用户音高再加。
- 资料里撤回的说法不要用：“假声拉低会改变口型”。

## 先锁再改（这一轮的前提）

ACE 的 AI 参数不存进工程，任何编辑都会让附近十几秒的 AI 参数重算（见 `ace-cli.md`）。所以：

1. `param_read.py` 读出当前版本（r2）四个参数的 AI 值（baseline）。
2. 四个参数**都**写成绝对值曲线：目标 = r2 的 AI 值 × 倍率，倍率为 1 的地方就是 r2 原值。
   - 离线写 `real*` 字段（`patch_params.py`），因为命令行 direct 层不收 < 0.3 的张力 / 假声（`param_write.py` 不预先拦，ACE 会报错）。
3. 先渲一版“全部锁定、倍率全 1”的对照，看锁得干不干净：
   - 《妄想感傷代償連盟》逐音 ≤ 0.04 dB；
   - 《反乌托邦》0.3–0.7 dB，这就是噪声底。

**没锁的标定要作废**。《反乌托邦》第一次没锁，测到的“气声效果”混进了别的参数的漂移：

- 气声对明暗 +19 dB/ln（锁后 +3.9）；
- 对 H1−H2 −11.6（锁后 +1.0，方向相反）。

## 标定：每次只改一个参数

在锁定的基础上，一次只把一个参数整段 ×1.5 或 ×0.67，渲染后逐音测信号特征（`voice_features.py`，5 ms 网格）：

- 响度：rms_db；
- 明暗：alpha_db，1–5 kHz 对 50 Hz–1 kHz；
- 气息噪声 / 齿音：hf_db，5–12 kHz；
- H1−H2：h1h2_db，前两个谐波差；
- 谐噪比：hnr_db，Praat 互相关。

洛天依 V1 的实测（锁定后整段 ×1.5，全部音符中位；**只代表这个声库、这首歌**）：

| 参数 | 主要变化 |
|---|---|
| 力度 | 响度 +6.3 dB；音色几乎不变（明暗 +0.2 dB，低音区约 +1 dB）——**这里力度基本就是音量** |
| 张力 | H1−H2 −9 dB（更“压”、更实），明暗 +2 dB |
| 气声 | 谐噪比 −4 dB（气息更多），明暗 +1.6 dB |
| 假声 | 明暗 −5.8 dB（更暗、更薄），谐噪比 +1.2 dB |

《妄想感傷代償連盟》的局部标定：

- 交界处力度 ×0.5（升余弦，半宽 ≤ 25 ms）→ 断开 −6.8 dB，作用很局部；
- 整段力度 ×0.67 → 内部电平 −6.7 dB；
- 整段张力 ×1.3 → 亮度只 +1.4 dB，H1−H2 却 −5.8 dB（声音明显更紧）。

升、降两个方向不对称；四个一起改时效果不是简单相加。

## 定目标与求解（规则在渲染第一版之前定死）

- **比什么**：逐音“原唱 − 合成”的差，按音区汇总。
  - 每组（各位原唱的独唱句、齐唱句）先扣掉自己在音符最多的音区上的整体差，去掉歌手音色和混音均衡的整体偏差；
  - 只比音区之间的相对关系。
- **不当目标的**：
  - 响度：原唱压缩过，起伏被盖住；
  - 5–12 kHz：原唱混音里的去齿音器会动态压低它。
- **求解**：
  - 用标定出的灵敏度，按升、降方向分开，做有界最小二乘；
  - 只追 70% 的差，倍率限制在标定过的 ×0.67–×1.5；
  - 换几组特征权重重解，方向会翻转的参数固定为 1。
- **校正**：先渲一版，看“实测 / 预测”，逐个校正一次。
  - 《反乌托邦》第二版（r3b）张力提到 1.42，H1−H2 比预测多降 7.6 dB，校正一次后才到位；
  - 《妄想感傷代償連盟》校正后实际 / 想要中位 1.09 / 1.00。
- **写入**：音区之间按音高平滑过渡，音符之间 40 ms 平滑。

## 两次的结果与教训

**《反乌托邦》（按音区改四个参数）**

- 改法：低音区（G3–E4）加气声 ×1.38–1.50、降假声 ×0.69–0.77、略提张力 ×1.09–1.20；最高 4 个音张力 ×1.22。
- 信号：低音区明暗差 13.2 → 2.0 dB、谐噪比差 −13.1 → −3.8 dB，音高、时值、断声都没变差。
- 盲听：用户一听就认出了改动版，原话“乙的前半段是经过改动的，感觉声音比较沙哑，但现在无需改动”。
- **教训**：气声别靠“原唱谐噪比更低”推到 ×1.5。谐噪比会被原唱的混响、混音压低，气声加到这个程度听起来就是沙哑。
  下次低音区先只降假声，气声 ≤ ×1.2，再听。不用谐噪比那组权重解出来的是：气声 ×1.10–1.24、假声 ×0.67–0.80。

**《妄想感傷代償連盟》（用户说“原唱更干脆”）**

- 先把“干脆”量化（`examples/…/r3_*.py` 与 `crisp_metrics.py`）：起音、句尾收音、音间断开深度、长音尾部衰减、长音内部起伏、亮度。
  原唱用去混响、原样两份参考取中间（去混响会放大断开，原样会填平）。
- 只用力度改：30 个浊音交界加凹陷（倍率中位 ×0.63）、20 个长音尾部下收（×0.68）。
- 信号：断开 −5.1 → −8.4 dB、尾部 −5.1 → −7.3 dB，落在两份参考之间；音高不变。
- 盲听：“差别很小，我感觉是甲”（甲 = r2）→ 成品仍是 r2。
- **教训**：
  - 起音改不动：声码器决定元音起振速度，ACE 的 AI 力度在音头本来就“冲上去再回落”。
  - 盲听后补测长期平均频谱（`ltas_compare.py`）：r2 在 2.5–5 kHz 比原唱暗 3–9 dB、8 kHz 以上暗 9–18 dB——“干脆”更可能来自高频。
  - 但用张力去追亮度会压得过紧；之后的 EQ 提亮盲听用户也没选（见 `mix-and-delivery.md`）。

## 原有知识里还没验证的

（来源：用户提供的《ACE-Studio-调教资料总汇》，见 vocal_pilot 的 `docs/ace-tuning-knowledge.md`）

- 乐句开头加呼吸，长句和高音前尤其需要。加之前先锁参数；加呼吸本身也会触发重生成。
- 高音（F5–C6）略降张力，或加一点假声并同时降张力。
- 力度包络按乐句起伏画：原唱压缩过时证据不足。
- 起音过冲、句尾叹气、句首短倚音：有原唱音高时已经照搬，做没有参考的原创时再试。
