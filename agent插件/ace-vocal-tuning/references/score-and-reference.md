# 谱面、时间网格与参考人声（都在基线之前做完）

调教前要先把三样东西定死：谱面（音高、时值、歌词都对）、时间网格（BPM 和偏移），以及参考人声（拿什么当尺子）。
这三样有错，后面量出来的“调教误差”其实是准备工作的错。

## 1. 谱面从哪来

| 来源 | 怎么读 | 坑 |
|---|---|---|
| UST（UTAU） | `extract_ust_zip.py` 解压（压缩包里的文件名是 Shift-JIS）→ `ust_inspect.py` 读成 JSON（480 tick / 四分音符，`Lyric` 为 `R` 或空是休止） | 一音一个读音假名：は 写成 わ、を 写成 お，长音并进前一个音；“ベタ打ち”谱面不保证准，和声更不保证 |
| USTX（OpenUtau） | **必须按 YAML 1.2 读（ruamel.yaml）** | PyYAML 会把歌词 `no` 读成 False；声部要逐个看（主唱 / 叠唱 / 和声）；罗马音、UTAU 写法要转假名（`a t`→っ、`i n`→ん、`si`→すぃ） |
| Pocket Singer 工程（`.ps_project`） | WinZip AES 加密的 zip，LibreSVIP 2.9.0 的 ps_project 插件读取 → 转 `.acep` → 导出音符 | 工程里可能内嵌去人声伴奏，可用来做参考人声；按作者的条款署名、不再配布 |
| MIDI / MusicXML / UfData | ACE 命令行 `import` 只认这三种，不认 UST / USTX | 多轨 MIDI 不能拿每个起音的最高音当主旋律 |
| 没有谱面 | ACE Vocal to MIDI 从去混响人声出初稿（`ace_v2m.py`，免费；《绯红》用过，做法见下面 1.1） | 音高准、音节不准：《绯红》209 个音只错 12 个音高（偏差中位 0.02 半音），但官方 232 拍里一致 156、认错 53、漏掉 23（并进相邻音） |

示例：`scripts/examples/` 里有四次试验各自的建谱脚本（UST、USTX、Pocket Singer、Vocal to MIDI 各一个）。

### 1.1 Vocal to MIDI 初稿怎么核对成谱面（《绯红》）

1. **量化**：原唱是 VOCALOID 时，音节都从网格点起。Vocal to MIDI 的起点有两簇（按辅音、按元音，差约 40 ms），落在同一个十六分里，就近量化到十六分；
   原本首尾相接的量化后仍相接。网格零点用节拍分析定，再在 ±40 tick 内搜整体偏移，取起点落在网格 ±20 tick 内最多的那个。
   真人原唱不一定在网格上，量化前先看起点分布。
2. **音高**：逐音取参考音高中位数（Praat、RMVPE），|偏差| ≥ 0.6 半音的逐个看轮廓。经过音、上邻音、滑音落点按参考改；
   上滑过冲、音符内滑音只记下来，交给音高轮。改完后检查调性（《绯红》降 B 大调以外没有音）。
3. **音节**：把识别的音节和官方读音（注音页换成假名、按拍切分）做半全局对齐，找出认错、漏掉、错位的地方；
   再按网格点的信号证据决定拆音和对位：能量凹陷（dip）、清音间隙（gap）、2–8 kHz 能量突增（flux）、前后音高。
   清辅音应有清音间隙，鼻音、流音只有小凹陷，元音开头的音节没有凹陷。
4. **助词、长音、促音**按原唱的信号定，不按字面：
   - 助词：へ 唱 え、を 唱 お（网格点上没有辅音凹陷）；《绯红》#119 写的是 は，但参考在那里有 65 ms 清音间隙，照唱 は；
   - 长音（官方写成 o→u、e→i）：MFCC 和同一首里音高相近的元音样本比（k=7 近邻），《绯红》5 处全是拉长前一个元音，不单独唱 u / i；
   - 促音：下一格参考是静音（−49～−62 dB）→ 音符只留一个十六分、后面空一格；下一格仍有声 → 写「-」，停顿交给下一个辅音；
   - 同元音的相邻音节：网格点凹陷浅于 −2.5 dB（没有重新起音）的并进前一个音或写「-」。
5. 修正全部写进 `docs/score_fixes.json`（只有序号，不含歌词），由脚本套用并自检：官方每个音节要么正好落在一个音上（顺序单调），
   要么写明并入的理由。示例：`examples/v2m_绯红/`。
谱面不走 ACE 的导入：用脚本读出音符和歌词，核对修正后，再由 `ace_build.py` 写进新工程。原谱的音高曲线、颤音不用，音高轮用原唱的曲线。

## 2. 谱面 JSON 的格式（所有脚本共用）

单轨（`pilot_score.json`）：

```json
{"meta": {"bpm": 220.0, "tpq": 480, "offset_tick": 79, "clip_start_tick": 93839, "clip_end_tick": 141519,
          "clip_sec": [53.318, 80.409], "window_sec": [54.318, 79.409], "language": "Japanese",
          "voice": "singer:18 洛天依 (Verse23)", "source": "谱面来源说明", "clip_name": "chorus1"},
 "notes": [{"idx": 0, "tick": 95599, "pos": 1760, "dur": 240, "pitch": 70, "lyric": "だ",
            "start": 54.318, "end": 54.4544, "target": true, "ust_src": "main", "ust_idx": 316, "ust_tick": 95520}]}
```

- `tick`：ACE 时间轴（参考音轨放在 0 s）；`pos`：片段内 tick（`tick − clip_start_tick`，可以不写：脚本用 `common.clip_pos` 从 tick 换算，
  写了就必须和 tick 一致）；`start` / `end`：秒。
- 延长音写「-」（ACE 的“空音符”效果：延续前一个音节；命令行不收空歌词）。「-」不送 G2P，phoneme list 里也没有它的行。
- 片段前后各留约 1 s（真实休止处），导出范围就是片段范围。
- `target: false`：参考在这个音上不可靠（加过效果的喊声、两位原唱重叠、分离几乎删光）——照唱，但不写目标音高、不计分、不测时值。
- `timing: false`：音高可以追，但参考在这一段测不准时值（例如去混响分离后这一段太弱）。
- 多轨：`{"meta", "tracks": [{"role": "main", "name": "洛天依_主唱", "notes": [...]}, {"role": "harmony", ...}]}`，第一条是主唱；`score_views.py` 拆成单轨视图给按单轨写的脚本用。

## 3. 定准时间网格（BPM 与偏移），调教前冻结

至少用两类证据，前、中、后段一致才算数：

| 方法 | 脚本 | 试验里的结果 |
|---|---|---|
| 谱面 / 文件名里的 BPM | — | 130、120、220 BPM |
| 伴奏节拍跟踪，前后半段分别算相位 | `examples/pocket_singer_反乌托邦/tempo_check.py` | 《反乌托邦》120.19 BPM，相位前半 +63、后半 +65.5 ms → 没有漂移 |
| 谱面音高轮廓 × 参考 F0 逐偏移比对 | `align_ust.py` | 《妄想感傷代償連盟》UST tick 0 = 0.045 s，三段 0.045 / 0.045 / 0.055 s，吻合率 72.5%，峰值 ±10 ms 内只降 0.5% |
| 谱面声部 × 官方清唱，前后半段 | — | 《超级超级超级讨厌》六个估计 1.263–1.286 s，均值 1.2755 s → 放在 1325t（1.274 s） |
| 投稿源 × 官方 WAV 互相关 | — | 源片 = 官方 − 0.032 s |
| ACE 节拍分析（`tempo analyze --file-path` → `tempo get-analysis`）+ 逐拍线性拟合 | `tempo_fit.py` | 《绯红》101.99 BPM；321 个拍点拟合 101.998，按 102 残差中位 6 ms、最大 40 ms，三段平均残差都在 ±2.5 ms 内 → 用 102，不变速 |
| 分离人声按小节的有声比例 | `vocal_sections.py` | 《绯红》找段落边界（前奏、主歌、铺垫、副歌、间奏），定一分钟版的区间 |

- 偏移差在 ±15 ms 以内视为不显著，不移动音符。
- 定下来的数写进 `docs/score-decisions.md`，之后不再改。网格错了，时值轮会把它当成辅音问题去“修”。

## 4. 参考人声：拿什么当尺子

按可靠程度：

1. **官方清唱 / 干声**（《超级超级超级讨厌》官方二创素材包）。
   - 注意叠唱：副歌里清唱是“高八度主唱 + 弱约 20 dB 的低八度叠唱”，Praat 跟主唱、RMVPE 跟低层。
2. **官方音轨 − 伴奏**（《反乌托邦》：减去 Pocket Singer 工程内嵌的去人声伴奏，增益 1.014）。
   - 无人声段残差比原曲低 34–36 dB；
   - 两位原唱轮流唱，重叠处（下一句压在上一句尾巴上）不可靠。
3. **ACE Stem Splitter 基础模式**（`ace_split.py` → `stems_collect.py`，原样一次、去混响一次）。
   - **音高、时值参考只用去混响那组**：原样分离的人声带混响、叠着低八度，Praat 67% 的帧落到低八度，和谱面只吻合 7%；去混响版吻合 72%。
   - 原样分离的人声是“原曲里人声的实际电平”，带伴奏试听用它定人声电平。
   - 两次分离的伴奏逐字节相同。

参考是混过音的成品时（2、3），边界和音色都只能当估计，报告里要写明。

### F0 提取

两个提取器，5 ms 网格：

- **Praat**：一律走 `common.praat_grid`。
  - 静音阈值 0.005：默认 0.03 会把低音区、轻的乐句判成无声，第一次试验因此返工过；
  - 按时间插值到网格：Praat 帧时刻落在半格上，取整会撞格，20 秒里 862 次碰撞。
- **RMVPE**：研究目录的 `rmvpe_local_extract.py`，10 ms 一帧，用 `f0_grid.py --rmvpe <json> <时长> <out.npy>` 换网格。

两个提取器差 12 半音的地方，要么是叠唱，要么是一方的八度错误。用谐波判断（`examples/ustx_超级超级超级讨厌/octave_probe.py` 的思路）：

- 候选基频 f 的奇次谐波（f、3f、5f）明显存在，真基频就是 f；
- 只有偶次谐波（2f、4f），真基频是 2f。

## 5. 谱面核对（`note_check.py`，基线之前）

逐音取音符中间 50% 的参考 F0 中位数，和谱面比：

- **八度候选**：|偏差| 与 12 相差不到 1。
  - 连续一段都差 12 → 整段改八度。《超级超级超级讨厌》的 USTX 从第 33 小节起高一个八度，35 个音降回。
  - 单音差 12 → 用谐波判断，多半是叠唱。
- **错音候选**：两提取器相差 < 0.5、有声比例 ≥ 0.6、偏差 ≥ 1.5 半音（第一次试验用 ≥ 2.5 且中段 IQR ≤ 1）。只标记，改不改看上下文。
- **滑音、装饰不是错音**：例如参考在 125 ms 内弧形升降、句尾上滑到顶再落下。这些留给音高轮，谱面不动。同一个手势在几处重复出现时，要改就一起改。
- **整体时间偏移**：音符掩码与有声掩码在 ±200 ms 内求最大重合。演唱比音符晚 15–20 ms 是正常的（辅音在前）。

四次试验的谱面改动量：

| 曲目 | 改动 |
|---|---|
| 《超级超级超级讨厌》 | 35 个音降八度、6 个单音修正 |
| 《反乌托邦》 | 0 处（偏差中位 0.07 半音） |
| 《妄想感傷代償連盟》 | 主唱 0 处、补唱段 2 处、和声 3 处 |
| 《绯红》（Vocal to MIDI 初稿） | 12 个音高；拆音 9 处；音节按官方读音改约 40 处；209 → 221 个音，官方 232 拍全部对上 |

## 6. 读音与歌词

- 用 ACE 自己的 G2P 逐音读一遍（`g2p_check.py`，不看上下文；「-」不送），全部要解析得了（有解析不了的音节时脚本退出码 1）。
- 写进工程后读回（`ace_readback.py`）：音符、歌词逐个一致，音素行全部解析，行数 = 音符数 − 延长音数。四次试验都做到 0 处不一致。
- **读回的音素要逐字过一遍**，ACE 唱错字只有这里看得出来（我们听不见）：
  - G2P 按字的默认读音，不看上下文。《刷到》（中文原创，2026-10-24）读回发现「还给你」的还读成 h-ai（应为 h-uan），句尾「呢」读成 n-i（应为 n-e）；
  - 读错的用 `phoneme set --note <UUID> --phoneme h uan` 覆盖，覆盖存进工程、重开不丢（读回 `isOverride: true`）。
- **日语**：
  - UST 的假名是读音，核对的是“假名 → 音素”这一步；
  - 去声化要看参考。例：`fu(30t)/ku(120t)` 两个音，30t 那个完全无声，按读音和去声化规律改为 く(30t) / ふ(120t)；
  - 助词、长音、促音按原唱信号定（上面 1.1 第 4 条）。
- **中文**：
  - 歌词逐字对照官方歌词；
  - 多音字逐个核对，例如：中 zh-ong、的 d-e、看 k-an、还 h-ai、么 m-e、要 y-iao、说 sh-uo、便 b-ian、只、为、没、会、少、长、都。
- **齐唱**（两位原唱同音同字）：同一歌手完全相同的复制轨只会叠在一起，唱一遍就够。
- **重叠的句子**：下一句压在上一句尾巴上时，放到第二条轨（第二声部）。
