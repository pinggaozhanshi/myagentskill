# 故障索引与项目证据

## 从症状回到共享根因

| 症状 | 优先检查 | 常见有效修复 | 无效捷径 |
|---|---|---|---|
| 长停顿/回访手势错 | 源姿势顺序、曝光表、缺姿势 | A→B→A按段复用，缺图才增绘 | 只找最近关键帧、全局抹平 |
| 最后一帧旧人/首帧带旧头 | 实际帧边界、图层有效区间、缓存 | 同时修切点和选图，检查邻帧 | 对四舍五入秒数再加常数 |
| 眼部/围裙白残影 | 字幕mask混到主体、cel映射 | 限ROI、同帧cel恢复 | 全局白阈值、盲扩大inpaint |
| 端茶手残影 | 景物恢复包含肤色 | 原人物轮廓内禁止恢复旧手 | 整片按颜色恢复 |
| 人物贴底错误、上下晃 | 整体bbox污染、逐帧缩放 | 锁比例、真实鞋底/贴边和稳定锚点 | 把花瓣算成鞋底 |
| 背景马赛克/该消失未消失 | 小图修补放大、前景层次 | 原分辨率局部修复、转场前景与消失区间 | 画面检测失败就保留原人 |
| 嘴型抖、分屏表情错 | 底图变化、永久槽位分配 | 共用下半脸底图、按出现区间切表情 | 为每个嘴型生成整个人 |
| 旧字阴影点、气泡断裂 | 边缘/阴影漏mask、circle误识别 | 实际背景色/组件保护/道具干净底图 | 只擦纯白核心 |
| 黑条歌词没替换/半个字提前出现 | 连通域粘背景线、阶段缓存、剪裁 | 受控矩形＋出现时刻＋阶段键 | 没有字框就永久不绘 |
| 淡出还见日文 | 阈值在低alpha失效 | 同位置全不透明参考＋经核实alpha | 再用高白阈值 |
| 心形里头像碎片 | 源切点与前一图层检测跨界 | 新镜头禁用旧头像cel，别强加旧字幕spec | 只涂碎片，不改区间 |
| 整曲慢慢不同步 | 采样率/tempo/剪切变化 | 多窗口查漂移根因 | 仅量一次起点 |
| 视频生成非常慢 | 逐帧全图inpaint、重复字层/全图混合 | 无需inpaint则跳过，字层阶段缓存，局部像素混合 | 缓存不含阶段导致旧字 |

## 真实案例：魔法女仆v1–v11

这些是2026-10-07最终验收记录的事实，不是新任务模板参数。

- 源成片4765帧、1920×1080、30000/1001fps，158.9921667s；人物原画目录最终包含312张PNG（包含旧稿/修订，不能当独特动作数）。
- v8：54个不同帧增绘、12个候选复用已有姿势、5张嘴型重绘、1张端茶空底板，另有5份修订保存。文件总量、有效采用量和候选覆盖不同。
- v9c：第1327帧仍有人物，第1328帧切空镜；近景贴底核查10处为0px间隙。鞋底轨迹排除花瓣后，结尾180帧平均对位误差0.011px、最大2px；不证明脸型/线条一致。
- v10：52句当前中文，636 notes，当前第47句为“我就是热爱歌唱的女仆”；5张道具无字底图按实际手势区间调用。123处最终编码样本校核，修过1159–1161空过渡、3946小字幕起点、3942–3945淡出、4305心形首帧和副歌栏出现。
- v11：中文歌曲44100Hz，6处精测lag同为−941 samples，因此补941点、21.3379ms；8处编码后复测残余lag0（8k测量分辨率0.125ms）。视频包内容SHA256保持相同；裁尾约1.039s、尾段RMS−97.37dBFS。真峰值−1.5dBTP。

**历史记录有修正关系**：v5说明曾把1327视为切入空镜；v9c的实际帧核查推翻了该判断。继承最新实测证据，不把每一份历史结论合并成“都正确”。

**本次真实失败基线**：早期流程曾使用时间上最近的图而长保持姿势、拿白色识别字幕伤到眼白、用含花瓣的bbox造成33px偏移；后续字幕首轮又用了旧cel、粘连字框、误伤圈和漏旧阴影。静帧通过后仍在编码首/末帧与淡出出现问题。这些错误产生了本包的门槛与根因路由。独立Agent基线已识别多数风险；零trim例没暴露的坐标歧义通过非零clipPos例再次验证。
