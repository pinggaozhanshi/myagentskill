# 人物与制作流程

## 接续与盘点

- 从入口说明和验收JSON找到被接受的成片；检查记录时间、实际存在的文件和哈希，而非只按版本号最大值。
- 扫描素材可读性、尺寸、RGB/RGBA、alpha范围、参考和修订状态。透明黑像素和不透明背景不能混为一谈。JPEG检查图不能替代透明原件。
- 清单至少记录`shot_id/source_frame/pose_id/file/revision/accepted/generation_reference/prompt/checksum`。采用状态与文件保存状态分开。
- 不重跑已成功的生成；缺失返回文件先检查持久化位置/归档。保存后更新下一张缺图、失败重试和可复用姿势。禁止把PNG文件数当独特动作数。
- 配色要求按镜头范围记录并核查实际采用的PNG；同名旧红裙与新蓝裙不可随机混用。

## 镜头、曝光与图层

先核定实际切场帧，再用`[start,end)`编译曝光表。检查所有边界的`start-1/start/end-1/end`，以及快速三连脸、条纹转场、漂浮到落地和人物消失时刻。不要因为背景检测失败就回退显示原人物。

曝光表描述每一段采用哪一张姿势图，允许回访更早的原画ID。重复动作应按源片重新映射；匹配算法只提供候选，手势/眼口/衣服与遮挡仍需同帧对照。先补确实缺少的姿势，再靠曝光调节节奏；长时间保持一张图可能造成停顿，胡乱补帧也可能改变动作。

通常背景、人物、前景转场/道具和字幕分层。具体谁在前面由原镜头决定；黑幕或条纹若应遮住人物，就不能放在人物后面。原场景修复仅限旧人物缺口，不恢复原肤色、瞳孔或手。

## 定位与抖动

每张原画先校准到目标镜头；同一曝光段固定变换，同镜头锁定比例。不在播放循环中用整体bbox反复缩放。

| 镜头 | 定位依据 | 需排除 |
|---|---|---|
| 裁到画布底部的近景 | 主体不透明下沿贴底，身体/肩线复核 | 字幕、散点和前景花瓣 |
| 倒置近景 | 贴顶并跟随原片横向轨迹 | 把倒置图误按脚底贴底 |
| 全身舞蹈 | 实际鞋底/地面轨迹＋身体稳定特征 | bbox内的花瓣、高光、漂浮碎片 |
| 手碰脸 | 经检查的脸部范围/稳定五官 | 肤色连通域把手合进脸导致尺度变化 |
| 多头像或分屏 | 每格出现区间与表情状态 | 永久把一个表情固定在一个槽位 |

如果原片真的有横移或上下动作，保留它。短窗口中值/低通只抑制测量噪声，窗口长度依据新片运动速度选择；本案5帧不是默认值。先验证锚点，再平滑，否则会把错误轨迹平滑得很稳定。

嘴型变体可共用下巴、颈部和衣领底图，仅替换嘴部区；检查区域外像素不变。眨眼、胸针扫光、闪光与人物图层分开，不能用一张静态插图冒充原本动态效果。

## 生图和时间估算

给生成器明确编辑目标、身份参考、源姿势、镜头裁切、服装配色、透明与不透明输出要求。若需要去字底图，要求保留手的具体姿势与线稿，而非重新设计整幅画。实际检查输出，不把请求透明等同于获得正确alpha。

估算只数未覆盖的独特姿势、需重绘的失败姿势、局部底图和修订；重绘与增绘分开。先用少量困难镜头测得单张耗时、采用率、修订次数和编码速度，再给区间估计。重复动作若已覆盖，不计成新增原画。要新增姿势还是修变换，从同帧对照决定。

## 样段验收

检查原片/合成同帧、实际编码样段、关键边界与动态播放。记录尺度、肩/腰/脚底变化；像素差峰值只能找可疑帧，不能独立判定抖动。真实镜头切换自然产生峰值。鞋底对位误差只证明地面轨迹，不证明头部、手部或画风完全一致。
